# kanope-infra

Dashboard perso de cartographie d'infrastructure. **Vanilla JS SPA buildée avec Vite** (aucun
framework, zéro dépendance runtime).

> **Hors production Kanopée** — projet personnel, non opérationnel, non déployé. Exclu du périmètre
> prod de la suite (voir [`../docs/`](../docs/README.md)). Distinct de `kanope-ansible` (l'IaC réelle).

## Démarrage

```bash
npm install      # Node 20 (voir .nvmrc)
npm run dev      # serveur de dev (hot reload)
npm run build    # build de production → dist/
```

Architecture détaillée dans [`CLAUDE.md`](CLAUDE.md).
